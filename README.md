# 会序 · 会议素材工作台

一个在当前 Mac 上运行的会议素材系统。每个本机账号有独立的会议系列、底稿和附件。服务仅监听 `127.0.0.1:8765`，不会自动发布到公网。

## 启动与登录

1. 双击 [启动会序.command](启动会序.command)，终端会启动服务并打开页面。若 macOS 首次阻止打开，可以在 Finder 中右键该文件，选择“打开”。保持终端窗口开启；关闭窗口会停止服务。
2. 在浏览器中打开 <http://127.0.0.1:8765/>，第一次使用选择“创建账号”。这是会序本机账号，并非 ChatGPT 登录。
3. 创建会议系列和会议。可以粘贴底稿或上传 Word（`.docx`）、Excel（`.xlsx`）、PDF、TXT、Markdown、CSV；文档内可提取的文字会追加到底稿，表格与原排版不保证完整保留。扫描图片型 PDF 需要先进行文字识别。

启动脚本在缺少依赖时创建项目自己的 Python 虚拟环境并安装必要依赖。Pi 安装在 `.pi-runtime` 中；缺少时脚本会通过 npm 重新安装。需要 Python 3 和 Node.js 22.19 或更高版本。也可手动执行：

```bash
python3 -m pip install -r requirements.txt
npm ci --prefix .pi-runtime --ignore-scripts --no-audit --no-fund --registry=https://registry.npmjs.org
python3 app.py
```

## 创建素材

- 在“项目与 KV”维护项目名称、对应学协会／基金会和 Logo，并分别上传无 Logo 的日程、串场、封面、嘉宾简介和双面席卡底图。在会议中选择项目与 KV，应用时会保存素材快照。当前的叠字位置和 A4 双面折叠方式按用户提供的南阳案例设计，其他构图需要进一步适配。
- 在物料工坊选择 KV 后会自动应用：海报和展架优先使用所选 KV 的日程底图，席卡优先使用席卡底图；若没有对应底图，页面会提示上传。也可在工坊为当前物料上传 KV 或点击“AI 生成 KV”；文字和 Logo 是独立图层。AI 结果仅应用于发起生成的物料，生成期间如果手动更换了同一物料的 KV，不会覆盖新上传的图片。
- 创建或编辑项目、KV 时，可分别勾选允许本机其他账号选择。共享的素材可被其他账号查看和应用，但只有创建者可以修改；会议资料仍按账号隔离。取消共享不会删除其他会议已经保存的素材快照。
- 先整理并核对会议日程。带 KV 的日程可导出 PNG、PDF；Excel 和 Word 仍可编辑。页面预览基于上一次保存的资料。
- 在“现场串场”按当前日程生成 PPT；可按日程添加嘉宾并补充照片、单位和简介，提供的资料会生成介绍页，缺失资料不会被编造。串场依赖本机 Node.js 和 Codex 随附的 Artifact Tool；日程或嘉宾资料修改后应重新导出。
- 点击“确认日程并生成名单”，系统按日程提取老师姓名并供人工核对，然后导出 A4 双面折叠席卡 PDF。日程定稿后再次修改，须重新确认；不明确的人名会提示人工补充。
- 在“会议底稿”中填写会议基本信息，上传底稿；右侧本地检查会提示常见缺失信息。点击“AI 整理底稿”可让 AI 根据底稿提取字段并补充问题；提取结果需人工核对，现有已填写字段不会被覆盖。
- 在“会议日程”中编辑环节和嘉宾名单，可导出 Word、Excel；名单每行一人，用于桌卡批量导出。
- 在“物料工坊”中选择海报、易拉宝 / 展架或桌卡，设置毫米尺寸、字体和主题色。支持上传 Logo、背景和 TTF / OTF / TTC 字体；上传的自定义字体需要包含中文字符。生成的图片保留可读的会议文字，AI 背景不会代替文字与 Logo 排版。
- 点击“保存为本系列默认版式”，之后该系列的新会议将继承各物料尺寸、字体、颜色、项目、Logo 和 KV；会议内容、嘉宾和日程不会继承。
- 在“主持串词”中生成模板或使用 AI 撰写，编辑后可导出 Word。缺失信息会标记为待确认。

图片导出目标为 150 DPI，受最长边 5000 像素和 2000 万像素上限影响，大尺寸物料的实际 DPI 会降低；PNG 内记录实际 DPI。PDF 为图片版。请在交付印刷前核对文字、尺寸、实际分辨率、色彩和出血要求。

## 连接 Pi 和 ChatGPT 订阅

在系统中打开“AI 连接设置”，点击“打开 Pi 登录”。在打开的 Pi 终端依次执行：

```text
/login openai
/login codex-images
```

按 Pi 和浏览器的提示，用你自己的 ChatGPT 账号完成授权，然后回到设置页面刷新状态。文字 AI 使用 Pi 的 OpenAI 登录；订阅生图使用项目内安装的第三方 `pi-codex-image-gen` 扩展的独立 `codex-images` 登录。文字处理与图片请求路由固定使用 `gpt-6.1-sol`，并先核对账号和 Pi 的可用模型；图片实际采用的图像模型由图片服务决定。扩展使用 Codex 的图片后端，依赖服务方的账户权限和接口可用性；发现本地授权文件不代表调用一定成功。发生错误时不会自动切换到按量计费 API，也不会自动重试一次生图请求。

点击 AI 操作后，相关会议内容或用户填写的画面要求会发送给 AI 服务。登录凭据保存在 `data/pi-accounts/<本机账号编号>/`，不要分享该目录或将它提交到版本库。不同会序账号的 Pi 登录目录相互独立。账号数据在 `data/` 内，电脑本机有文件系统访问权限的其他用户仍可能读取；如果需要对外提供多人访问，需要另行建设部署、访问安全和备份。

## 连接国产生图 API

在“AI 连接设置”中的“国产生图服务”分别填写：

- **快速档：Seedream 5.0 Flash**。在[火山方舟控制台](https://ark.volcengine.com/region:cn-beijing/apikey)创建 API Key，确认账号可调用 `doubao-seedream-5-0-flash-260915`，然后保存到快速档。
- **进阶档：Qwen-Image 3.0 Pro**。在阿里云百炼开通北京地域的模型服务，填写该地域的 API Key 和业务空间 ID（例如 `llm-xxxxxxxx`）；具体查找方式见[百炼接入信息](https://help.aliyun.com/zh/model-studio/beijing-access-information)。

保存状态只表示凭据已保存，不代表服务商已经验证密钥或开通模型权限。在物料工坊选择“AI 生成背景”，即可选择快速档、进阶档，或继续使用原有 ChatGPT 订阅；两种国产档位不需要 Pi 登录。生成时会议名称和画面要求会发送给所选服务商，系统生成背景后会另行叠加会议文字和 Logo。

国产模型通过对应服务商按量计费，具体价格和免费额度以服务商控制台为准。一次操作只提交一次生图请求，失败或超时不会自动重新生成、也不会自动切换到另一家服务；超时后仍可能发生计费。返回的图片若下载不完整，系统会在限制次数和时间内续传或重新下载同一张图片，不会再次提交生图请求。API Key 保存在 `data/image-providers/` 下当前账号对应的本机文件中（文件权限 600，目录权限 700），不返回到前端，也不会提交到 Git；这不是加密存储，请妥善保护电脑账户和备份。可在设置中更换或移除密钥。

```bash
python3 -m unittest discover -s tests -v
```

测试在临时目录创建账号和资料，覆盖账号隔离、Word / Excel 底稿导入、Word / Excel 日程、PNG / PDF / 批量桌卡、系列版式继承、公式注入防护以及模拟 AI 图片任务。模拟测试不能证明真实 ChatGPT 登录或生图成功。
